## Side Project — Hotel Marcel Car Service Redesign: at a glance

- **Try it:** open the [live app](https://nsteinyale.github.io/hotel-marcel-ride-redesign/). The guest and driver phones run side by side on a computer; on a phone, use the Guest/Driver switch.
